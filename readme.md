## 📚 Tecnologías y Conceptos Clave

A lo largo de la asignatura se abordan las herramientas fundamentales para el desarrollo web moderno full-stack:

### 1. HTML (HyperText Markup Language)
El lenguaje de marcado estándar que define la estructura y el contenido semántico de las páginas web (encabezados, párrafos, formularios, enlaces y elementos multimedia).

### 2. CSS (Cascading Style Sheets)
El lenguaje de diseño utilizado para controlar la presentación visual, diseño responsivo, tipografía, paletas de colores y animaciones de las interfaces construidas sobre HTML.

### 3. JavaScript
Lenguaje de programación interpretado, dinámico y orientado a eventos que dota de interactividad a las páginas web en el navegador, además de ejecutarse en el servidor mediante entornos como Node.js.

### 4. TypeScript
Un superconjunto (*superset*) tipado de JavaScript desarrollado por Microsoft. Añade tipado estático opcional, interfaces y características avanzadas que facilitan la escalabilidad y detección temprana de errores en proyectos medianos y grandes.

### 5. NestJS
Un framework progresivo para **Node.js** enfocado en la construcción de aplicaciones backend eficientes, confiables y escalables. Utiliza TypeScript por defecto y se basa en una arquitectura modular fuertemente influenciada por Angular (inyección de dependencias, controladores, servicios y decoradores).

### 6. React.js
Una biblioteca declarativa y basada en componentes para **JavaScript/TypeScript** desarrollada por Meta, diseñada para construir interfaces de usuario (UI) reactivas, reutilizables y de alto rendimiento mediante el uso de un DOM virtual.
